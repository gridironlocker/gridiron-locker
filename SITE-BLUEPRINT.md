# Gridiron Locker — Site Blueprint

> The website itself: architecture, page map, design system, SEO layer, and
> how every page gets generated. (For the business/marketing view, see
> `BLUEPRINT.md`.) Last updated 2026-08-30.

---

## 1. What the site is

A **static, data-generated SEO storefront**. Every page is plain HTML/CSS/JS
(no server, no build framework) and is **generated by `src/build.py`** from the
data snapshots in `data/`. The live site is `site/`, deployed to GitHub Pages
via `.github/workflows/deploy.yml`.

- **Live URL:** https://gridironlocker.github.io/gridiron-locker
- **Stack:** static HTML + vanilla CSS + vanilla JS (single `app.js`)
- **Hosting:** GitHub Pages (no server, no database)
- **Commerce:** none on-site — every CTA links out to the Viralstyle campaign checkout

---

## 2. Architecture at a glance

```
data/  (collections, products, facts, order, trends, people)
   │
   ▼  src/build.py  (reads data + config, writes every page)
   │
   ▼
site/  ──(deploy.yml)──▶  GitHub Pages
   ├── index.html                 homepage
   ├── <collection>/index.html    collection landing pages
   ├── shop/<slug>/index.html     134 product pages
   ├── guides/...                 4 SEO buying guides
   ├── about|contact|faq|shipping|size-guide|privacy|trademark-notice|404
   ├── assets/style.css + app.js
   ├── img/                       1,019 self-hosted images
   └── sitemap.xml, sitemap-images.xml, robots.txt, feed.xml, webmanifest
```

Key property: **you never hand-write a page.** Add a design on Viralstyle, the
scraper pulls it into `data/`, the builder generates its product page. Copy is
templated but varied so no two pages read alike.

## 4. Page anatomy

### Homepage (`index.html`)
Top-to-bottom sections (from `build.py`):
1. **Promo bar** — thin announcement strip
2. **Header / nav** — brand + links + mobile nav
3. **Hero slider** (`hero hslider`) — crossfading hero art per collection (6.5s dwell)
4. **Countdown / ticker** — kickoff countdown + news ticker (Week 1 hook)
5. **Week 1 section** (`wksec`) — season opener urgency
6. **Why strip** (`whystrip`) — "why this locker" value props
7. **4 collection sections** — one block per team, accent-colored
8. **Custom apparel section** (`customsec`) — custom-design offer + form
9. **Trust badges** + **footer** (disclaimers, links, trademark route)

### Product page (`/shop/<slug>/`)
- **Breadcrumbs** (`crumbs`) → home / collection / product
- **Gallery** (`gallery` → `stage` + `thumbs`) — multi-view product imagery
- **Buy box** (`buybox`):
  - price row (price + slashed compare-at + save % + star rating)
  - urgency strip (limited-run messaging)
  - style selector (`stylelist`), size selector (`sizes`), color swatches (`swatchrow`)
  - checkout note + trust badges + shipping reassurance
- **Prose** (`prose reveal`) — unique, design-specific copy
- **Detail columns** (`detailcols`) — two spec/benefit panels
- **Related products** — grid of 4 `card` items (internal linking)
- **Sticky mobile buy bar** — never leaves the screen on phones

### Collection page (`/<team>/`)
- Hero (accent-colored), breadcrumbs, product grid (`#grid` of `card` items),
  intro copy + FAQ + internal links.

### Static pages (`simple_page` / `page_static`)
About, Contact, FAQ, Shipping, Size guide, Privacy, Trademark notice, 404 —
single-template pages with shared header/footer.

## 6. Front-end behaviour (`site/assets/app.js`)

Vanilla JS, single file. Features:
- **Gallery** — `setStage`/`step` stage + thumbnail switching, gentle crossfade
- **Option groups** — `toggleGroup` for style/size/color selection
- **Price** — live price/compare-at/save rendering
- **Countdown** — `tick`/`pad` kickoff countdown timer
- **Sticky header** + **back-to-top** — on scroll (`stuck`, `tt.on`)
- **Sticky buy bar** — `maybeShow` reveals the mobile buy bar at the right scroll depth
- **Touch/swipe** — `touchstart/move/end` handlers (gallery swipe)
- **Contact form** — builds a `mailto:` payload from name/email/team/idea fields
- **Reveal on scroll** — `reveal` animation hooks

## 7. SEO layer

- **Unique per page:** `<title>`, meta description, canonical, Open Graph +
  Twitter cards on all 158 pages.
- **Schema.org JSON-LD** (validated) — per product page:
  `Product` + `Offer` + `AggregateRating` + `Brand` + `BreadcrumbList` +
  `FAQPage` (7 Q&A) + `Organization` + `WebSite` + `SearchAction` +
  `OfferShippingDetails` + `DefinedRegion` + `Audience`.
- **`sitemap.xml`** — 153 URLs with lastmod/priority/changefreq.
- **`sitemap-images.xml`** — image sitemap (product imagery = ranking asset).
- **`robots.txt`** — allows everything including AI engines
  (`GPTBot`, `PerplexityBot`, `ClaudeBot`), `Crawl-delay: 1`,
  disallows only `/marketing/plan.json`.
- **`feed.xml`** — RSS with collection + product items (fresh-content signal).
- **Internal linking:** home → collections → products → related → guides → back.
- **Trademark-safe framing:** "fan-made / independent / not affiliated"
  disclaimers sitewide + dedicated trademark notice with takedown route.
  *(Note: this protects the site's keyword posture; it does NOT protect the
  social accounts — see `BLUEPRINT.md` §9.)*

## 8. The builder (`src/build.py`)

One file generates the whole site. Template functions:

| Function | Produces |
|---|---|
| `build_model()` | assembles the in-memory site model from `data/` + config |
| `head()` / `header()` / `footer()` | shared HTML shell (meta, nav, footer) |
| `countdown_bar()` / `ticker()` / `newsticker()` | season urgency widgets |
| `week1_section()` / `why_strip()` / `trust()` | homepage strips |
| `hero_slides()` | homepage hero carousel |
| `card()` / `railcard()` | product grid cards |
| `page_home()` | `/index.html` |
| `page_collections_index()` / `page_collection()` | collections |
| `page_product()` | the 134 product pages |
| `page_guides()` / `page_season()` / `page_404()` | guides, season hub, 404 |
| `simple_page()` / `page_static()` | about/contact/faq/etc. |
| `assets()` | emits `style.css` + `app.js` |
| `relativise()` / `sync_marketing()` | path + marketing-sync helpers |

Config (`src/config.json`) drives site name, tagline, domain, contact email
(base64), Twitter handle, currency, and the IndexNow key.

## 10. Data contract (`data/`)

| File | Role |
|---|---|
| `collections.json` | collection-level SEO/brand data (mirrors `collections_data.py`) |
| `products.json` / `products_live.json` | scraped Viralstyle product detail |
| `facts.json` | per-design copy facts (`name`, `art`, `kw`, `theme`) |
| `order.json` | the canonical list of 134 design slugs |
| `trends.json` | 10-day headline snapshot |
| `people.json` | current vs throwback player/coach context |

`src/catalog.py` holds the human-written copy facts that make each generated
page read authentically.

## 11. Deployment

- **`deploy.yml`** — on push to `main`, uploads `./site` to GitHub Pages
  (Pages artifact → deploy). No build step; the site is committed pre-built.
- **`refresh.yml`** — daily 06:15 UTC: Monday crawls (`scrape_list.py`,
  `scrape_products.py`, `dl.py`), refresh `trends.json`, rebuild, auto-commit
  `Auto-refresh: trends + rebuild <date>`.

Local preview: serve `site/` with any static server
(`python3 -m http.server` in `site/`).
