The 🔄 button above runs the only automatic source that still answers without keys (Lemmy). Reddit's unauthenticated JSON and Bluesky's searchPosts now return 403 to a browser, so they were removed instead of being faked. Everything below runs in your own logged-in browser — nothing is scraped here and no reply is ever sent for you.

1 · Assisted search opens a recent-post search in a new tab, logged in as you
2 · 📥 Send to Finder bookmarklet

Drag the gold button to your bookmarks bar (or copy it and make a bookmark). Open a search result page, then click the bookmark: it reads the posts that are visible on screen, opens this Finder in a new tab and ingests up to 60 of them. Reads: X articles (tweetText + the status link with <time>), Reddit posts/comments (new shreddit-* and old .thing[data-permalink]), Google results, and anywhere else the text you have selected plus the page URL.

📥 Send to Finder Tip: on a page with no matching posts, select the post text first.
3 · Paste posts

One post per block, a blank line between blocks. Every block must include the post's URL — a block without a link is rejected, never guessed. Counts are shown after ingesting.
