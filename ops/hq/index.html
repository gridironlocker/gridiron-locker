Bot menu

Re-scan the 4 collection pages for new designs.
scrape_products.py
Crawl each design's full product data + images.
replay_updates.py
Re-inject directly-published campaigns (idempotent).

Add-a-product

New directly-published campaign? One command:

python3 add_campaign.py <slug> <collection>

Example: python3 add_campaign.py my-new-design cleveland-browns → merges into data/campaigns_extra.json → python3 replay_updates.py && python3 dl.py && python3 src/build.py. Collections: cleveland-browns, dallas-cowboys, green-bay-packers, michigan. Add --dry-run to preview without writing. Full docs: HOW-TO-ADD-A-DESIGN.md Option A+.
