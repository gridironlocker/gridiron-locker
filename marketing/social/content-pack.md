## 0. Posting-time key (used on every caption below)

- **US time = America/New_York (Eastern)** — the audience clock.
- **Morocco time = Africa/Casablanca** — your clock.
- **Formula (Aug–Oct 2026): Casablanca = Eastern + 5 hours.**
  Eastern 12:00 → Casablanca 17:00 (same day). If a converted time passes
  midnight, it gets a `+1d` marker (e.g. Eastern 19:30 → Casablanca 00:30 +1d).

## 5. Engagement rules that raise reach

1. **Reply to every comment in the first hour** — early replies tell the
   algorithm the post is active. One word counts ("Dawg Pound!" "Facts.").
2. **Pin a comment** that invites more replies — "Which team should we drop
   next? Comment below."
3. **End every caption with a question** — the single biggest comment driver.
4. **One link** — Instagram/TikTok give you one bio link; send it to the
   storefront, never a splash page.
5. **Story + feed, same day** — the story points to the feed post ("New fit on
   the feed — go vote in the comments"), doubling exposure.
6. **Hashtag split** — 3–5 niche tags in the caption, 5–8 broad tags in the
   first comment on Instagram, so the caption stays clean and reach still lands.
