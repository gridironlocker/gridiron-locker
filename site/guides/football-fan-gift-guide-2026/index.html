Gifting without knowing their size

The single best trick: measure a shirt they already like flat across the chest and match the numbers on the size guide. Fleece (hoodies, crewnecks) runs roomier than tees; if you are unsure or between sizes, order one size up. Every product page lists the exact sizes that design offers.

How do I pick a size for a gift?

Measure a shirt the person already owns flat across the chest and match the numbers on the size guide - or use the hoodie hint: fleece styles run roomier than tees. If you are between sizes or unsure, order one size up.
