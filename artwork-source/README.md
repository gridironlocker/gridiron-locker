# artwork-source

Original hand-made banner artwork (PNG masters) kept for reference only.

Nothing in this folder is served. The live hero banners are the five
1920x1080 JPGs in `site/img/hero-*.jpg`, which the build references directly.
These PNGs were previously sitting in `site/img/` unreferenced, so every
GitHub Pages deploy shipped ~18 MB of artwork no page ever loaded.

If you replace a banner, export a new 1920x1080 JPG (~500-700 KB) into
`site/img/` and keep the master here.
